# 设计决策与限制

1. **复用检索，独立资产。** 复制运行所需的已清洗语料和索引到 assets/corpus；BM25 使用 SQLite URI `mode=ro&immutable=1`，向量使用只读 memmap。没有自动重建旧索引的代码入口。数据更新必须整体生成一致版本后切换配置并重启，不支持混合版本热更新。
2. **统一候选深度。** Java 从共享配置读取 candidates，并在实际调用中显式传给 Python。评测同样调用 Java 或明确指定相同值，消除旧路径 50 与离线 100 的差异。
3. **不以位置编号表示跨轮引用。** 证据 ID 是申请号、摘要哈希和 Unicode code point 范围。摘要变化即改变 ID；当前问题只接收本次选中文档的证据集合。
4. **边界可测，语义不伪装。** 审计从规范摘要重建证据，不信任传入引文。有效引用、跨文档引用、小整数、单位和区间均有程序测试。实体关系、否定和因果尚未实现可靠语义判定，不输出“忠实度 95%”之类标签。
5. **先核验再提交。** SSE 提供检索来源与阶段反馈，结果完成审计后提交。无效引用或缺失数值的内容进入 review，不混入正文；语义仍由使用者核对。模型输出 schema 错误时保留原文并失败，不无限重试。
6. **单一模型入口。** 所有在线生成和查询改写均进入 Java 有界队列。Python 负责检索和确定性处理。默认并发 1 适配 8GB 卡，工作台不宣称多节点吞吐。
7. **取消需到传输层。** LangChain4j Ollama 固定版本的模型级 Flow 方法未实现，使用其 JDK HTTP 流订阅承接取消，覆盖首响应之前。Java 终态与 GPU 内核终止是不同信号，验收会明确区分。
8. **可恢复业务状态。** 调研、候选、备注、查询与任务结果落盘；重启标记未完成任务，不自动重试生成。已完成任务的内存事件缓存 5 分钟后清理，持久化记录保留。
9. **本机访问边界。** 共享访问令牌配合工作区随机密钥；所有业务资源带归属过滤；不提供公网部署、企业身份系统或权限委托。浏览器凭据丢失不会绕过隔离自动恢复旧工作区。
10. **结果可分享。** Markdown 报告带申请号、原文片段、版本与限制；CSV 导出防止以公式起始的备注被表格软件执行。浏览器展示通过 textContent 创建，不执行摘要或模型中的 HTML。
11. **性能口径。** 分开记录排队、模型首内容、模型总生成和整体任务时间。使用模型返回的 token usage，不把网络分块数量当 token。短重复请求与长比较报告分别解释。
12. **质量评测分层。** 保留旧合成排序缓存用于回归指标口径复算；独立需求式题集与待审阅候选池单列。没有人工相关性标签时不生成“真实用户准确率”。
