# 种子评测报告 v0

## 1. 评测集

150 题，全部为**合成题**，不做人工校验，直接作为回归基线：

| 类型 | 数量 | 造法 | gold |
|---|---|---|---|
| factoid | 60 | 取专利标题 + IPC，让 Qwen3 写技术问题（不看摘要） | 该专利 |
| comparison | 50 | 同一 IPC 大类下取两件专利，模板生成“《A》与《B》在技术方案上的主要区别” | 两件专利 |
| unanswerable | 40 | 问申请人名称 / 专利诉讼 / 法律状态——语料里没有 | 无 |

产物：`eval/gold_150.jsonl` + `eval/report_150.json`。生成脚本：`eval/build_eval.py`。
60 题的 `eval/gold.jsonl` 保留为小样本对照。

> 注意：factoid 题只给标题+IPC，天然无法区分同主题近邻专利，因此 **单 gold recall 是下界**，不等于系统真实可用性。

## 2. 结果

检索 150 题；答案侧抽 18 题（每类 6 题）。

| 指标 | 数值 | 样本 |
|---|---|---|
| factoid recall@5 | **0.850** | 60 |
| comparison all-gold hit@5 | **0.860** | 50 |
| comparison any-gold hit@5 | **1.000** | 50 |
| factoid 引用命中（gold 在 sources） | **0.667** | 6 |
| comparison 引用命中（任一 gold） | **1.000** | 6 |
| 平均 faithfulness（LLM 逐条判定） | **0.606** | 12 条可答题 |
| 不可答拒答率 | **1.000** | 6 |
| 平均端到端延迟 | 约 10.9 s | 18 |

> 答案侧只有 18 题，方差很大：同一系统在 60 题子集上 faithfulness 为 0.868，在 150 题子集上为 0.606。检索指标样本更大（60/50），相对更稳。

## 3. 60 题种子集的 factoid 失败分析

30 题中 gold 的排名分布（150 题目集只做了汇总，未逐条重算）：

| 排名 | 数量 |
|---|---|
| 1–5 | 21 |
| 6–10 | 2 |
| 11–20 | 2 |
| 21–50 | 1 |
| top-50 未出现 | 4 |

- **5/9 失败是近邻专利**：如“翻板闸门” vs “自锁型翻板式隔绝门”、“移位寄存器” vs “移位寄存器、驱动电路…”。问题只由标题生成，无法区分；这些近邻专利可能同样能回答，单 gold 口径偏严。
- **4/9 是真实召回失败**：如“双酰胺基卤代苯类化合物 → FXa 抑制剂”，问题用化学术语，gold 标题不含这些词，稠密向量没召回。
- 提升路径：rerank 候选 15→50（+0.033）、标题字符 bigram 叠加（+0.033），合计 0.633→0.700；标题+摘要 rerank 无额外增益。HyDE 仅救回 1/5，且丢了 1 个原命中，未纳入主链路。

## 4. 局限

1. 合成题、单 gold；150 题的检索样本为 60/50，答案侧只有 18，统计强度弱。
2. LLM judge 与生成模型同为 Qwen3-4B，存在自评偏差；未做人工校验，`faithfulness` 仅作相对参考。60 题子集 0.868、150 题子集 0.606，方差明显。
3. 不可答拒答原先只匹配“资料不足/无法回答”，漏掉了“未提及/未披露”；已修正，修正后为 1.0。
4. 对比题 gold 为同一 IPC 大类下的两件专利，部分主题相关性弱，不代表真实对比需求。

## 5. 下一步

1. 150 题合成集已作为主报告，不做人工校验；单 gold、合成题的指标统一按下界解读。

3. 针对 4 个真实漏召回做 query expansion / HyDE 消融（HyDE 已验证 1/5，未上线）。
4. judge 校准改为规则/交叉模型对照，不依赖人工标注。

## 6. 复现

```powershell
python eval/build_eval.py --factoid 60 --compare 50 --unans 40 --out eval/gold_150.jsonl
python eval/run_eval.py --gold eval/gold_150.jsonl --answer-n 18 --tag 150
```

## 7. 150 题合成集

- `eval/gold_150.jsonl`：60 factoid + 50 comparison + 40 unanswerable。
- `eval/report_150.json`：150 题检索 + 18 题答案的完整结果。
- 不做人工校验；单 gold、合成题，指标为下界；60 题 `gold.jsonl` 保留为小样本对照。
