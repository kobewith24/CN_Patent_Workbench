# P4 校验 v2：结果与结论

## 设置

- 60 道 A 层问题，hybrid+rerank 取 top5，4B 生成答案。
- 答案按 v2 口径切成 claim：**所有句子都算**，没有 `[n]` 的句子直接计为 unsupported。
- 三个判定器：4B LLM、Erlangshen 中文 NLI、bge-reranker（阈值 0.5）。

## 客观指标（不需要人工校准）

| 指标 | 值 |
|---|---:|
| claim 总数 | 424 |
| **引用覆盖率 citation_coverage** | **0.595** |
| LLM 支持率（带引用内） | 0.515 |
| LLM 全量不可支持率 | 0.708 |
| NLI 支持率 / 不可支持率 | 0.624 / 0.641 |
| reranker 支持率 / 不可支持率 | 0.942 / 0.434 |

**v0 的 faithfulness 只统计带引用的句子**，那 40.5% 无引用断言完全不在分母里。所以旧的 0.606 / 0.868 是“已引用部分里被支持的比例”，不是答案整体可信度。按 v2，整体不可支持率是 0.71。

## 人工校准（40 条，20/20 分层）

| 判定器 | kappa | 一致率 | 仅事实型子集（29 条）kappa |
|---|---:|---:|---:|
| LLM | 0.050 | 0.525 | 0.181 |
| NLI | 0.198 | 0.625 | 0.316 |
| reranker | −0.084 | 0.775 | −0.061 |

AUC：NLI 0.667，reranker 0.686。人判正例 33/40。

## 结论：claim 级“是否被支持”目前不可信

三个判定器和人都不一致，原因不是某个模型差，而是**任务定义本身有三处漏洞**：

1. **claim 是多命题长句。** 一句里四个事实，摘要支持三个、缺一个，人说“支持”，严格判定说“不支持”。两边都对，但口径不同。
2. **混进了不可验证的元陈述。** 答案里有“未涉及喷射泵”“关联性不足”“结论：”这类句子——它们不是事实断言，本来就无法用摘要验证。剔掉这类后 kappa 有提升（LLM 0.05→0.18，NLI 0.20→0.32），但仍远低于 0.7。
3. **reranker 不适合做校验。** 阈值 0.5 下 94% 判支持，kappa 为负——它衡量“语义相关”，不衡量“有依据”。

**所以 P4 可信的产出只有一个：引用覆盖率 0.595。** 它只数 `[n]`，不依赖任何判定器。

## 对服务的处理

- `/verify` 已切到 v2：返回 `citation_coverage`、`support_rate`、`unsupported_rate`，不再用单一 `faithfulness` 掩盖无引用断言。
- `support_rate` 在文档里必须标注**未校准**，不能当 headline 数字用。

## 下一步（留给后续）

- 原子化 claim：按逗号/分号再拆，或让模型输出主体-谓词-数值三元组。
- 定死标注口径：要么“严格蕴含”，要么“部分支持”，二选一，再重标一次。
- 元陈述过滤：`未涉及/不涉及/关联性不足/结论：` 这类直接不参与校验。

在此之前，不要对外声称“逐句引用校验准确率”。
