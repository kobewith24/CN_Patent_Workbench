# P4 校验：从“语义判定”改为“证据审计”

## 为什么放弃语义判定

先按原计划做了 40 条 claim 的人工校准，三个判定器和人都不一致：

| 判定器 | kappa（40 条） | 仅事实型子集 |
|---|---:|---:|
| LLM（4B） | 0.050 | 0.181 |
| NLI | 0.198 | 0.316 |
| reranker | −0.084 | −0.061 |

原因不是某个模型差，是任务定义本身有歧义：claim 是多命题长句（人说“部分支持”、严格判定说“不支持”）、答案里混了大量评价性元陈述（“未涉及/证据不充分”）、标注口径没定死。继续调判定器或再标一次，都是在这个歧义里打转。

**所以换口径：不判断“语义上是否支持”，只检查能被机械验证的东西。**

## 新口径：四类检查

1. **引用完整性**：每句有没有 `[n]`，编号是否越界。
2. **数值对齐**：claim 里的数字/比例/单位，必须能在被引摘要里原样找到（全半角、`～~—` 归一，先剥掉 IPC 码和 `Tween-20` 这类名称里的数字）。
3. **术语对齐**：claim 里的技术词（jieba 词、长度≥2、去通用词）在被引摘要中的覆盖率。
4. **元陈述过滤**：`未涉及/未说明/证据不充分/关联性较弱/（注：…）` 这类评价句不算事实断言，单独统计。

## 结果（60 条答案 / 424 条 claim）

| 指标 | 值 |
|---|---:|
| claim 总数 | 424 |
| 元陈述占比 | 0.165 |
| 引用覆盖率 | 0.542 |
| 含数值的已引用 claim | 22 |
| **数值无出处率** | **0.046** |
| 术语覆盖率（均值） | 0.770 |
| **有据可查率 grounded** | **0.435** |

术语覆盖率的分布：p10 = 0.474，中位 0.805，p90 = 1.0；阈值取 0.5 / 0.6 / 0.7 时，grounded 率分别是 0.486 / 0.435 / 0.367，结论对阈值不敏感。

## 典型样例

`a011`：claim 说“海藻糖（1%–20%）、BSA（0.5%–3%）、Tween-20（0.4%）”，被引摘要只写了“1%‑20% 的海藻糖和 1‑10% 的牛免…”。**0.5%、3%、0.4% 三个数在摘要里找不到**——这是可指认的编造，不是“语义判断”。

## 这套口径能说什么、不能说什么

**能说**：这句结论里的数值/术语能不能在引用原文里找到；找不到的，逐条列出缺哪个 token。

**不能说**：
- 抓不到“用词都对、关系说反”的错误。
- 同义改写会漏配（字符级包含能缓解一部分）。
- grounded 不等于“答案正确”，只等于“没发现无出处的具体信息”。

对外只能说“**数值与术语可溯源**”，不能说“逐句引用校验准确率”。

## 服务接口

`/verify` 不再调用 LLM，改为纯规则审计，返回：

`citation_coverage` / `numeric_unsupported_rate` / `term_coverage` / `grounded_rate` / `meta_rate`，
每条 claim 附 `numbers_missing` 与 `term_coverage`。

`faithfulness` 字段保留，但语义已改为 `grounded_rate`。
